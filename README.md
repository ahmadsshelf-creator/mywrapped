# MyWrapped

A polished, modern music player web app with local music library, playlists, listening statistics, and daily Wrapped summaries.

## Features

- 🎵 **Local Music Library** - Import your own music files (MP3, WAV, M4A, OGG, FLAC, AAC)
- 🎧 **Beautiful Music Player** - Persistent mini-player with full Now Playing screen
- 📋 **Playlists** - Create, manage, and play custom playlists
- ❤️ **Favorites** - Mark and organize your favorite songs
- 📊 **Daily Wrapped** - Beautiful daily listening summaries with statistics
- 🏆 **Achievements** - Unlock badges based on listening behavior
- 📈 **Listening Statistics** - Track plays, time listened, streaks, and more
- 📱 **Responsive Design** - Optimized for desktop, tablet, and mobile

## Privacy First

- All music files remain on your device
- No song uploads to any server
- All data stored locally using IndexedDB
- Full control over your music and listening data
